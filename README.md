
# Java 8 & JUnit Practice Projects

### 1. Inventory Management System

Manage store products with Java 8 Streams for filtering and sorting, custom exceptions for validation, and JUnit tests for adding/searching products.

### 2. Student Grading System

Process student marks using Streams, assign grades with functional interfaces and lambdas, handle custom exceptions, and validate with JUnit.

### 3. Online Order Processing

Validate orders using Optional and Predicate, enforce payment and address rules via custom exceptions, and test flows with JUnit.

### 4. Employee Leave Tracker

Track employee leaves with Java 8 streams and lambdas, implement leave policies, use custom exceptions for limits and dates, and verify with JUnit.

### 5. Library Book Lending System

Manage borrowing and returning of books using Streams and Optionals, enforce limits and availability via exceptions, and test all cases with JUnit.
